# Day 2 - Python Data Structures Toolkit
 
## Overview

This project was completed as part of the **MLBench Summer Internship - Day 2**.

The application is a menu-driven Python program demonstrating the use of Python's core data structures. 

## Features

### List Operations
- Find Largest Number
- Find Second Largest Number
- Remove Duplicate Values
- Reverse a List
- Find Common Elements

### Tuple Operations
- Count Occurrences
- Convert Tuple to List
- Convert List to Tuple

### Set Operations
- Find Unique Values
- Union of Sets
- Intersection of Sets
- Difference of Sets

### Dictionary Operations
- Create Student Record
- Calculate Average Marks
- Word Frequency Counter
- Nested Dictionaries
