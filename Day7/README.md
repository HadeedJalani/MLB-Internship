# Day 7 – Data Cleaning & Visualization

## Overview

On Day 7, I learned how to clean datasets using Pandas and visualize data using Matplotlib and Seaborn. I performed various preprocessing tasks, generated multiple charts, and built a Student Performance Dashboard to analyze student records effectively.

---

## Topics Covered

### Data Cleaning (Pandas)

- Loading CSV datasets
- Checking missing values
- Removing duplicate records
- Renaming columns
- Creating new columns
- Sorting datasets
- Saving cleaned datasets

### Data Visualization

- Bar Chart
- Histogram
- Scatter Plot
- Pie Chart
- Box Plot

## Data Cleaning Steps

- Loaded the student dataset
- Checked for missing values
- Removed duplicate records
- Renamed columns
- Created an `Average_Score` column
- Classified students into performance categories
- Sorted students by average score
- Saved the cleaned dataset

---

## Visualizations Created

- Average Score Per Student (Bar Chart)
- Average Score Distribution (Histogram)
- Python vs Machine Learning Marks (Scatter Plot)
- Performance Categories (Pie Chart)
- Subject Marks Distribution (Box Plot)

---

## Key Insights

- Most students performed in the Good and Average categories.
- Python and Machine Learning scores showed a positive relationship.
- The dashboard quickly identifies top-performing students and students needing improvement.

## Challenges Faced

## Lessons Learned

- Data cleaning is an essential step before analysis.
- Visualization makes patterns and trends easier to understand.
- Pandas, Matplotlib, and Seaborn work together effectively for data analysis.
