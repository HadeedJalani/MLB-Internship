# Student Grading System 

## Description
This project was developed as part of the MLBench Summer Internship - Day 1 assignment.

The program collects a student's information, accepts marks for multiple subjects, calculates the total and average marks, assigns a grade based on predefined grading criteria, and displays a formatted report.

---

## Features

- Student information input
- Multiple subject support
- Marks validation (0–100)
- Automatic average calculation
- Grade calculation
- Pass/Fail status
- Clean terminal report
