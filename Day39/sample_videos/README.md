# Day 39 Crossing-Case Videos

Add two real test videos to this folder:

- `crossing_case_01.mp4`
- `crossing_case_02.mp4`

The videos should contain people crossing paths or partially occluding one another.

For each video, compare:

1. Whether tracking IDs remain stable.
2. Whether duplicate ENTRY events are produced.
3. Whether EXIT events are generated correctly.
4. Whether the ROI count remains reasonable.
5. Whether changing the tracker from ByteTrack to BoT-SORT improves results.

Do not commit copyrighted footage unless you have permission to use it.
