# Student Score Prediction System

## Overview

This project demonstrates a complete Machine Learning workflow using Python and Scikit-learn.

The objective is to predict a student's Python marks using other academic features such as Mathematics, Statistics, Machine Learning, Attendance, Program, and Age.

## Features

- Data Loading
- Data Preprocessing
- Label Encoding
- Train-Test Split
- Feature Scaling
- Linear Regression Model
- Model Evaluation
- Prediction Visualization
- Streamlit Web Application

## Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Streamlit

## Evaluation Metrics

- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- R² Score

## Learning Outcomes

- Understood data preprocessing
- Applied feature engineering
- Built a regression model
- Evaluated model performance
- Created an interactive Streamlit application
