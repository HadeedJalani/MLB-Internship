# Day 38 sample videos

Put 5 or more legal-to-use security/people videos in this folder.

The Streamlit app has a "Sample folder" mode that can process all videos in
this folder in one run.

Supported formats:

- MP4
- AVI
- MOV
- MKV
- WEBM

Recommended sources:

- Pexels: https://www.pexels.com/videos/
- Pixabay: https://pixabay.com/videos/
- your own recordings

Prefer fixed-camera scenes such as entrances, hallways, classrooms, shops or
public areas.

Keep source/license information for every public clip. Do not redistribute
videos whose license does not permit repository use.
